# prueba-asv-frontend

Frontend de la aplicación de control meteorológico, desarrollado con Angular 18.

## Requisitos previos

- Node.js
- npm

## Instalación

Clona el repositorio y accede al directorio del proyecto. A continuación, instala las dependencias:

```bash
npm ci
```

## Ejecución en desarrollo

Inicia el servidor de desarrollo con el siguiente comando:

```bash
npm start
```

Por defecto, la aplicación estará disponible en:

http://localhost:4200/

## Compilación

Para compilar la aplicación, ejecuta:

```bash
npm run build
```

Los archivos generados se guardarán en el directorio `dist/prueba-asv-frontend`.

## Pruebas

Para ejecutar las pruebas configuradas en el proyecto:

```bash
npm test
```

## Tecnologías

- Angular 18
- TypeScript
- RxJS
- Node.js y npm
